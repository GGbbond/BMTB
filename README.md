# 双电机对拖测试台软件包

本仓库提供 Linux x86_64 软件包下载，请前往 [Releases](https://github.com/GGbbond/BMTB/releases)。

原项目与源码：https://github.com/bxirobotics/bxi_motor_test_bench

下载 `.run` 安装包后，执行：

```bash
chmod +x motor_inspection-linux-x86_64-installer.run
./motor_inspection-linux-x86_64-installer.run
```

适用平台：Ubuntu 22.04 x86_64。也可使用 Release 中的 `.tar.gz` 压缩包。
